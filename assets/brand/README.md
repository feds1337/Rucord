# Rucord brand

Original minimalist R monogram with a speech-bubble tail. Flat azure #2563eb plate, white mark; no fonts or third-party marks.

- `rucord.svg`: master vector, 256×256.
- `rucord-flat.svg`: identical flat variant.
- `rucord-mark.svg`: white monochrome silhouette, trimmed for the atlas.
- `rucord-1024.png`: large raster preview.
- `rucord-tray.png`: black transparent template for macOS.

Platform icons in `packaging/` and atlas cell 58 share this artwork. `tools/generate-icons.py` pins the SVG hash. Original project attribution remains in LICENSE-MIT and THIRD_PARTY_NOTICES.md.
