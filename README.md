# Rucord

<p align="center"><img src="assets/brand/rucord-1024.png" width="160" alt="Логотип Rucord" /></p>

Неофициальный нативный клиент Discord на Rust и egui. Проект основан на [Serein](https://github.com/ViceVerse-cz/Serein); оригинальные лицензии и уведомления об авторстве сохранены. Rucord — самостоятельное оформление и русский перевод, а не официальный продукт Discord.

## Что изменено

- Название приложения, окон, установщика, пакетов и значков — Rucord.
- Минималистичная буква R в форме сообщения, без стороннего логотипа.
- Русский каталог дополнен всеми ключами английского интерфейса. Выберите «Русский» в настройках языка; при системной русской локали язык определяется автоматически. Сообщения пользователей и сторонние расширения не переводятся.
- Обновления и каталог расширений направлены в этот репозиторий. Пока репозиторий приватный, анонимная проверка обновлений и загрузка каталога с GitHub могут быть недоступны.

## Сборка

Нужны Rust из `rust-toolchain.toml` и платформенные зависимости: [инструкция](docs/platform-support.md).

```sh
cargo run --locked --features demo -- --demo
cargo xtask check
cargo xtask package
```

Демонстрационный режим использует синтетические данные. Голос входит в сборку. Работа с реальным Discord этим режимом не проверяется.

Данные Rucord хранятся отдельно от Serein; старые аккаунты и кэши автоматически не импортируются. Экспортируемые символы Wasm и суффикс `.serein-extension` сохранены для совместимости расширений.
